# 给家长的安装说明

LexiQuest（词境冒险）装在电脑上玩。进度记在这台电脑上。如果另外用浏览器打开，那边的进度是另一份，不会跟着这台电脑上的存档一起变。这边清掉，那边还在。

下面只讲怎么把桌面版打开。不需要懂编程。

## Mac

1. 点左上角的苹果菜单，再点「关于本机」。
2. 看「芯片」那一行。写着 Apple M（比如 M1、M2、M3、M4）就下载名字里带 `mac-arm64` 的压缩包。
3. 如果没有「芯片」，而是「处理器」写着 Intel，就下载名字里带 `mac-x64` 的压缩包。
4. 下载的是一个 zip。双击解开。
5. 把里面的 LexiQuest 拖进「应用程序」文件夹。

第一次打开会被系统拦住。这是因为这个程序没有苹果的正式签名，不是电脑坏了。按下面做，不要去关掉 Gatekeeper（那个开关不要动）：

1. 在「应用程序」里双击 LexiQuest，让它被拦住。第一次被拦时点「完成」，别点「移到废纸篓」。
2. 打开「系统设置」，点「隐私与安全性」。
3. 往下翻，找到 LexiQuest 旁边的「仍要打开」，点它。点了「仍要打开」之后，还要再确认一次。
4. 再确认之后，输入这台 Mac 的登录密码。

「仍要打开」大概只保留 1 小时。过了这个时间还没点，就再双击一次 LexiQuest，按钮会重新出现。

进度保存在这个文件夹里，名字是小写的 `lexiquest`：

`资源库/Application Support/lexiquest`

「资源库」默认是隐藏的，可以按 ⇧⌘G 打开。在访达里按这个键，把上面的路径贴进去就行。

用你自己的用户文件夹写出来，就是：

`/Users/你的用户名/Library/Application Support/lexiquest`

把 LexiQuest 拖进废纸篓、或者从「应用程序」里删掉，这个文件夹还在，进度不会跟着被删掉。

## Windows

下载的是一个 `.exe` 安装包。双击它。

如果弹出「Windows 已保护你的电脑」：

1. 点「更多信息」。
2. 再点「仍要运行」。

这是因为安装包没有微软的签名。

如果 Windows 11 开了「智能应用控制」，它会直接拦住，页面上没有「仍要运行」。这也是没签名造成的。不要关掉「智能应用控制」。微软现在的说明是：可以在「Windows 安全中心」的设置里关掉它；最近的 Windows 更新允许不重装系统就重新打开。被拦住时不要在这台电脑上安装桌面版。说明原文：<https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions>

进度保存在这个文件夹里，名字是小写的 `lexiquest`：

`C:\Users\你的用户名\AppData\Roaming\lexiquest`

也可以从资源管理器的地址栏输入 `%APPDATA%\lexiquest` 然后回车。

卸载 LexiQuest 不会删掉这个文件夹，进度还在。
