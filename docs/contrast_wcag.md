# 文字对比度

按 WCAG 2.x 相对亮度，只比较文字填充色和它后面的底色。描边写在表里，不拿来算比值，也不能靠描边过关。达标线一律是 4.5:1。禁用标签填充色 `#3F2E25` 仍列出，记为禁用豁免。

底色取游戏实际在画的颜色。按钮、芯片和标题牌取该状态图集帧里标签落点的平涂中位色：赤陶 `#A9432B` / 悬停 `#AE4E36` / 按下 `#A04433`，深青 `#1F6F64` / 悬停 `#2C776B` / 按下 `#266B65`，选中芯片 `#266B65`，标题牌 `#EAD8BD`。珊瑚 `#E76F51` 和青绿 `#2A9D8F` 只留在血条、节点、图标和选项圆槽的图形上。家长页标题和学堂计数直接铺在插画上，底色是文字锚点处的插画像素。村子任务条、目标条和奖励条是半透明矩形，底色是叠完村子画面之后的颜色。

字重是代码里写的字重。标题字体没有另写字重时按 400。大字（24px 及以上，或加粗且不小于 18.67px）也不降到 3:1。
