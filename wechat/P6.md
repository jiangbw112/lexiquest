## Privacy draft

The current web save stays on the device under `lexiquest.save.v1`. The parent PIN is stretched with PBKDF2-SHA256 at 100000 iterations and is not sent anywhere by this port. The WeChat page does not call a login API, does not upload the save, and does not enable cloud development storage.

If a later build adds an account, a nickname, a device id, or word audio, that collection has to be written into the privacy guide before any upload. This draft does not authorize that collection.
